# 秉羲小程序源码说明

本目录是秉羲纺织 ERP 的微信小程序工程。源码保留可读的页面、组件、服务与工具结构，可使用微信开发者工具直接打开。

## 运行

1. 导入本目录。
2. 在 `project.config.json` 中使用项目 AppID，开发联调也可选择测试号。
3. 编译运行。首次启动按部署配置页填写服务器地址。

## 工程结构

- `app.js`、`app.json`、`app.wxss`：应用入口、页面与分包声明、全局样式。
- `pages/`：主包页面。
- `packageA/`、`packageB/`、`packageC/`、`packageDebug/`：业务分包与调试页。
- `components/`：可复用页面组件。
- `libs/`：接口服务、登录、权限与打印等业务工具。
- `assets/`：包内静态图片与图标。
- `@babel/`、`miniprogram_npm/`：开发者工具构建 npm 后生成的运行时依赖。

## 校验

提交前运行仓库的小程序静态门禁与 Node 测试。真机渲染、服务器地址、合法域名和打印效果需在目标环境单独验收。
